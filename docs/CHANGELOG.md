| v32 | **不做种模式改为前置释放种子，根治 qB I/O 错误弹窗**：原流程处理中段就移走暂存文件、末尾才删种，窗口期 qB 活动任务对被移走的文件报 `file_open` I/O 错误（每集必弹、不影响入库）。现 `process()` 开头先按 `QBR_SEED_ACTION` 释放任务（`delete` → `deleteFiles=false` 删任务留文件；`pause` → 前置暂停），再搬移入库；dry-run 不动 qB。代价：处理失败时种子已不在 qB，文件保留在暂存/待归档，`--retry` 可补 |
